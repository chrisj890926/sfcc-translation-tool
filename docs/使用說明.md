# SFCC XML 翻譯工具 — 使用說明

把 SFCC 的 **Product Catalog** 或 **Page Designer Library** XML 翻成多國語言(預設
日文 ja-JP、韓文 ko-KR、德文 de-DE、法文 fr-FR)。它只翻需要翻的欄位,不動結構、
網址、型號與規格,翻完的檔案可直接匯入 SFCC(MERGE)。

---

## 1. 登入

1. 開啟網址:**`<填入你們的網址>`**(例如 `https://xxx.up.railway.app`)
2. 瀏覽器會跳出帳號 / 密碼視窗,輸入公司提供的帳密:
   - 帳號:`<APP_USERNAME>`
   - 密碼:`<APP_PASSWORD>`

> 找 IT / 管理者索取帳密。

---

## 2. 操作步驟

### 步驟 1 — 選擇模式
- **Product XML** → 產品目錄(`<catalog>`)
- **Page Designer XML** → 內容 library(`<library>`)

### 步驟 2 — 上傳 XML
把從 SFCC 匯出的 XML 拖進上傳區,或點擊選檔。**可以直接上傳整包匯出檔。**

### 步驟 3 — 填入 Product IDs(⚠️ 重要)
在 **Product IDs** 欄位輸入你要翻譯的產品 ID,**用逗號分隔**:

```
elite130, gx-iii-gold-850, masterliquid-pro-120-non-sleeve
```

- 系統會**只抽出這幾個產品**來翻,其他上千個產品完全不動 → 又快又省。
- **上傳整包卻不填 Product IDs 會被擋下**(避免不小心翻整包、產生高額費用)。
- 只有小檔(單一或少數產品)才可以留空直接翻。

### 步驟 4 — 選擇目標語言
勾選要翻譯的語言(可多選)。

### 步驟 5 —(選填)Protected Terms
不想被翻譯的字詞(型號、品牌、縮寫)。**通常保持預設即可。**

### 步驟 6 — 按「Translate」
畫面會出現進度條,顯示目前階段、已翻 / 略過數量、預估花費與剩餘時間。

### 步驟 7 — 下載
完成後按 **Download** 取得翻譯後的 XML。

---

## 3. 進度畫面看什麼

翻譯是背景執行,進度會依序經過:

```
Reading XML → Reducing Catalog/Library → Scanning → Translating
→ Writing XML → Validating XML → Completed
```

同時顯示:目前產品 / 元件、目前語言、已翻 / 略過 / 失敗數、Token 用量、
**預估花費(USD)**、已用時間與預估剩餘時間。若有做擷取,會顯示
「Catalog/Library reduced: 12000 → 3」。

---

## 4. 翻完之後 → 匯入 SFCC

1. 把下載的 XML 交給負責匯入的人。
2. 在 Business Manager 用 **Catalog / Library Import**,匯入模式選 **MERGE**
   (只會更新這些產品的翻譯欄位,不影響其他產品)。

> 進階(選配,給技術同仁):匯入前可用驗證工具比對「原始匯出檔 ↔ 翻譯檔」,
> 確認只有目標語言被改、結構完好,結果會顯示 **SAFE / NOT SAFE / BASELINE
> MISMATCH**。指令見專案 README 的 *Pre-import validation*。

---

## 5. 常見問題

**Q：按 Translate 後跳出「Product IDs is required for large full-catalog/library uploads…」**
A：你上傳了整包匯出檔卻沒填 Product IDs。請在 Product IDs 欄位填入要翻的產品 ID。

**Q:進度顯示「not found」某個 id**
A:那個產品 ID 在檔案裡找不到(可能拼錯或大小寫不符)。請核對正確的 `product-id`。

**Q:某些產品「沒有變化 / 沒被翻譯」**
A:通常是那個產品的原文(x-default)本來就空白、或只有型號名沒有可翻譯的文字。
需要翻的話,要先在來源補上內容。

**Q:翻譯很久**
A:產品越多、文案越長越久。建議一次翻 **10–50 個產品** 一批,不要一次太多。

**Q:網址打開顯示要輸入帳密**
A:正常,輸入公司提供的帳號密碼即可。

---

## 6. 注意事項

- **一次不要翻整包型錄**(上千個產品),費用會很高;請用 Product IDs 分批翻。
- 大家共用同一把翻譯金鑰、**共用同一份帳單** → 請只翻你真正需要的產品。
- 上傳完整 library(可能上百 MB)會比較慢,請耐心等進度條。
- 有問題找 IT / 管理者。

---

## 7. 找不到 Product ID?

Product ID 就是 XML 裡 `<product product-id="...">` 或
`<content content-id="...">` 的值。可以:
- 從 SFCC Business Manager 產品頁的網址 / ID 取得,或
- 用文字編輯器打開匯出的 XML,搜尋 `product-id=` 查看。
